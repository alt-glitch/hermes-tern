## Glide installed

Glide is off until you turn it on. Set it up with:

```
hermes glide onboard
```

It reads your local sessions (read-only), keeps the corrections you gave, lists them, and checks
that each one can be found again. Nothing leaves your machine. When the list looks right:

```
hermes glide onboard --enable      # or /glide on in any chat
```

Prefer to be walked through it? Ask Hermes to "set up Glide": the bundled `glide:onboarding` skill
runs the same checks, then helps you review what was kept before you turn it on.
