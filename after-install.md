## hermes tern is installed

Open a Tern pane and run:

```sh
hermes tern
```

**Pull requests (optional).** The PRs the agent links open beside the chat in Tern's PR plugin, which reads GitHub with the GitHub CLI (`gh`). Install it once per machine:

```sh
tern plugin install github.com/alt-glitch/tern-plugins/prs
```

The chat works without it; the PR pill then opens PRs on GitHub.
